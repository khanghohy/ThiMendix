📥 Tải file Excel mẫu (.xlsx)

📋 Hướng dẫn đưa 314 câu hỏi lên Google Sheets:

  1. Bấm nút 📥 Tải file Excel mẫu (.xlsx) ở trên để tải file De_Mendix_Advanced_314_Cau_Hoi.xlsx về máy.
  2. Mở Google Sheet của bạn > Chọn Tệp (File) > Nhập (Import) > Tab Tải lên (Upload) > Chọn file Excel vừa tải.
  3. Chọn "Thay thế trang tính hiện tại" (Replace spreadsheet) rồi bấm Nhập dữ liệu (Sẽ có đủ 8 tab: master 314 câu + 7 đề thi).
  4. Bấm nút Chia sẻ (Share) góc trên bên phải Google Sheets > Đổi quyền truy cập chung sang: "Bất kỳ ai có đường liên kết đều có thể xem" (Anyone with the link can view).
  5. Quay lại đây bấm 🔄 Đồng bộ ngay từ Google Sheet. Ứng dụng sẽ tự động nạp toàn bộ câu hỏi và lưu vào bộ nhớ cache để bạn học tập cả online lẫn offline!
